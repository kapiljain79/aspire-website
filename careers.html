Senior · Architect Canada - Remote Contract

Senior Network & Cloud Security Architect

Design and deliver multi-vendor network, security and cloud projects, from on-premises data centres to Azure and AWS.

About the role

Aspire IT Systems delivers network, security and cloud projects for enterprise and public-sector clients across Canada, directly and on behalf of national partners. You will design, implement and migrate multi-vendor network and security environments, from on-premises data centres to Azure and AWS.

What you will do

  • Design and deploy next-generation firewalls (Fortinet FortiGate, Palo Alto Networks, Cisco FTD/FMC) on-premises and in Azure/AWS, including HA, NAT, VPN and segmentation.
  • Plan and execute data centre migrations: legacy core/access to spine-leaf (Cisco ACI, NDFC/VXLAN EVPN) and on-prem workloads to Azure, AWS and Azure VMware Solution.
  • Build cloud network architecture: hub-spoke / Virtual WAN, Transit Gateway, ExpressRoute / Direct Connect, NVA/firewall insertion.
  • Deploy SD-WAN and SASE (FortiSD-WAN/FortiSASE, Prisma SD-WAN/Prisma Access, Meraki).
  • Run assessments, write HLD/LLD and migration runbooks, and lead change windows without business impact.
  • Act as the client-facing technical lead and escalation point.

Must have

  • Hands-on, production experience with at least two of: Fortinet FortiGate, Palo Alto NGFW, Cisco FTD/ASA.
  • Cisco routing and switching at depth: BGP, OSPF, EIGRP, VLANs/STP, HSRP/VRRP, QoS; Nexus platforms.
  • Data centre networking: Cisco ACI and/or NDFC/VXLAN EVPN, spine-leaf design and migration.
  • Cloud networking in Azure and AWS, with at least one completed on-prem-to-cloud migration.
  • Strong documentation and change-management discipline.

Good to have

  • CCIE (Enterprise Infrastructure, Data Center or Security), or CCNP.
  • Fortinet NSE 4/7/8, or the current equivalents FCP / FCSS / FCX.
  • Palo Alto PCNSE (retired July 2025) or its successor NGFW Engineer; SSE Engineer / SD-WAN Engineer.
  • AZ-104, AZ-700, AZ-305; AWS Advanced Networking Specialty or Solutions Architect.
  • Cisco ISE, SD-Access/Catalyst Center (DNAC), Meraki.
  • Automation: Python, Ansible, Terraform, REST APIs/Postman; AI-assisted network operations.

Technology ecosystem

Fortinet Palo Alto Networks Cisco FTD/FMC Cisco ACI NDFC / VXLAN EVPN Azure AWS SD-WAN SASE Meraki Terraform Ansible Python
